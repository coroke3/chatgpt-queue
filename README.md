# ChatGPT Queue Assistant (ChatGPT キューアシスタント)

Web上のChatGPT（[chatgpt.com](https://chatgpt.com) / [chat.openai.com](https://chat.openai.com)）およびGemini（[gemini.google.com](https://gemini.google.com)）に、**人間らしいタイピングと待機時間を再現した疑似キュー（待ち行列）機能**を追加するChrome拡張機能（Manifest V3）です。

AIが回答を出力している最中でも次の質問をどんどんスタックでき、回答終了後に**人間が読んで考えてタイピングしているかのように**次の質問を自動送信します。

---

## 主な機能と特徴

### 1. 1行1プロンプト一括追加（Bulk Insert）
- **1行ごとのプロンプト一括登録**:
  - テキストエリアに貼り付けた複数行のテキストを、1行＝1つのキューアイテムとして瞬時に登録可能。
  - 前後の空白トリム、空行の自動スキップ、リアルタイムの件数カウント表示に対応。
  - 空行区切り（2連続改行）や `---`（ハイフン3つ）区切り方式も選択可能。
  - 単一チャットタブへの登録はもちろん、全チャットへの一括分散投入（全タブ一括追加）にも対応。
- **ショートカットキー**: モーダル内でも `Ctrl + Enter` / `Cmd + Enter` で即座に追加実行可能。

### 2. 複数行指示プロンプトの入力制御（Enterで改行・Ctrl+Enterで送信）
- 設定画面で「Enterキーでキュー追加/送信」の切り替えが可能。
  - **OFF時（複数行入力モード）**: `Enter` で自然に改行。`Ctrl + Enter`（または `Cmd + Enter`）でキューへ追加・送信。
  - **ON時**: `Enter` で送信・キュー追加、`Shift + Enter` で改行。
  - どちらのモードでも `Ctrl + Enter` / `Cmd + Enter` による即時送信・キュー追加に対応。

### 3. 生成中のスマート自動スクロール（下端張り付き追従）
- ChatGPT・Geminiが回答をストリーミング生成中、スクロール位置が下端付近（140px以内）に張り付いている時のみ自動スクロールでテキストを追従。
- ユーザーが過去の会話を読もうと上スクロールしている場合は自動スクロールを一時停止し、不快なスクロール飛びを防止。下端に戻ると再び自動スクロールを再開。

### 4. キュー大量追加時の固定ヘッダー & スクロール制御
- キューが何十件〜何百件追加されても、画面上部にヘッダー（折りたたみボタン、バッジ、一括追加、クリア、設定ボタン）が固定表示（`sticky`）。
- キュー一覧部分のみが独立して縦スクロールするため、パネルが画面外に押し出されて閉じられなくなる問題を防止。

### 5. 省電力化とバックグラウンド最適化
- アイドル時およびバックグラウンド非表示タブ（`document.hidden`）でのチェック頻度を動的に調整（1000ms〜2500ms、ハートビート3500ms）。
- 不要なDOM監視を抑制し、長時間の並列稼働でもCPUおよびバッテリー消費を最小限に抑制。

### 6. モノクロアイコン & ポップアップ画面のシンプル化（絵文字全廃）
- 拡張機能アイコンおよびfaviconを洗練されたミニマルなモノクロ（ダークチャコール〜モノクロ階調）に統一。
- ツールバーポップアップ画面は絵文字を完全撤廃し、現代的でシンプルなカードデザインを採用。

### 7. マルチタブ一括管理ダッシュボード & 回答結果ビューアー
- **開いているChatGPT・Geminiを自動検出**: タブからの自己登録がない場合も一覧に表示し、対象タブから回答とキューの状態を取得し直します。未接続のタブには再読み込みの案内を表示し、バックグラウンドで更新が遅れたタブも一覧に保持します。
- **すべてのChatGPT・Geminiタブの回答結果とキューを1画面でリアルタイム閲覧**:
  - ウィジェット上部のアクション、または拡張機能ポップアップからワンクリックで開けます。
  - 開いているすべてのチャットタブが最新のデザインカードとして一覧表示されます。
  - **回答結果の閲覧**:
    - AIが回答を出力中（ストリーミング中）もリアルタイムにテキストを受信・表示。
    - 回答完了後、質問内容（Prompt）と回答（Answer）をダッシュボード上で直接閲覧できます。
    - **ワンクリック回答コピー**: 「コピー」ボタンで回答全文をクリップボードにコピー可能。
    - **過去の会話履歴**: カード内で過去のQ&A履歴もアコーディオン展開して閲覧可能。
  - **待機キューの管理**:
    - カード内のタブで「回答・結果」と「待機キュー」をシームレスに切り替え。
    - キューの並び替え、削除、最優先即時送信。
    - ダッシュボードから直接該当タブへプロンプト追加（Enterで追加、Shift+Enterで改行、IME保護）。
    - ワンクリックで「タブを開く」ジャンプ、一時停止/再開、キュー全クリア。
  - **フィルター・検索バー**:
    - 「すべて」「回答中・完了」「キューあり」のワンクリック絞り込みや、チャット名・プロンプトのキーワード検索に対応。

### 8. ネイティブに溶け込む洗練されたミニマルUI
- **今のChatGPT / Geminiのデザイン言語に準拠**:
  - ギラギラしたネオンや装飾を廃止し、本来のすっきりとしたモノトーン＋クリーンな角丸・ピルボタンを採用。
  - 入力欄横の Queue ボタンも標準のピルボタン風に溶け込みます。
  - ダークモードも特有のダークグレー（#212121 / #2f2f2f）に完全準拠。

### 9. 複数タブ完全対応・タブ独立並行実行 (Multi-Tab Independent Queues)
- 各タブ（各チャット）ごとに**完全に独立したキュー**を持ちます。
  - 例: タブAには「プログラミングの質問」を5個、タブBには「翻訳・リサーチの質問」を3個、それぞれ別のキューを登録して同時に進行できます。
  - 各タブが互いに一切干渉することなく、**並行（同時）にそれぞれのチャットで回答完了を検知して自動送信**します。
- **バックグラウンド（非アクティブ）タブでも自動継続**:
  - 別タブを開いて作業していても、バックグラウンドにあるタブが回答完了を検知し、自律的に次のプロンプトを投入し続けます。
  - 同一タブをリロード（F5）しても、そのタブのキューは保持されます。

### 10. 回答完了の徹底判定（誤送信防止）
- **多層的なストリーミング検知**:
  - Stopボタン（`data-testid="stop-button"`、日英のaria-label）の監視
  - ストリーミングクラス（`.result-streaming`、`[data-is-streaming="true"]`）や点滅カーソル（`.cursor`）の監視
  - 送信ボタンの `aria-disabled` 属性チェック
- **2.0秒間の安定性確認（Quiescence Check）**:
  - Stopボタンが消えた直後もすぐには送信せず、**2秒間連続してストップボタンが現れず、送信ボタンが完全に活性化している状態**が続くことを確認します。
- **送信直後クールダウン (4秒)**:
  - 送信実行直後は最低4秒間待機し、応答生成（Thinking / ストリーミング）が開始されるのを確実に待ちます。

### 11. たまにコピペ風に入力（Mixed Mode）
- 人間はすべての文章を1文字ずつ手打ちするわけではありません。メモ帳や外部エディタから貼り付けることもよくあります。
- **文章の長さに応じた自動コピペ判定**:
  - 長文（150文字以上）: 約 75% の確率でコピペ風入力
  - 中文（60〜150文字）: 約 40% の確率でコピペ風入力
  - 短文: タイピングメイン
- コピペ時も即送信するのではなく、**貼り付け後に人間が目視確認するディレイ（約1秒）** を挟んでから送信ボタンを押すため、極めて人間的です。

### 12. タイピングの「人間らしい揺らぎ」とタイポ再現
- **単語ごとのバースト入力**: 単語内は速く（22〜38ms/文字）、単語と単語の境界で微小なポーズを挿入。
- **句読点・改行での思考ポーズ**: `。` `、` `！` `？` 改行の後に 250〜500ms の一息ポーズ。
- **思考の逡巡**: 数十文字に1回、タイピングの手が一瞬止まるリアルな思考時間を再現。
- **リアルな打ち間違い（Typo & Backspace）**: 約 1.2% の確率で隣接キーを誤打し、一瞬止まってから Backspace で消して正しい文字を打ち直します。

### 13. ダークモード / ライトモードの完全対応
- カラーテーマ（`.dark` クラスや `data-color-scheme`）およびブラウザの `prefers-color-scheme` をリアルタイム監視し、UIの配色が自動連動。
- 設定モーダルから「自動 / ダーク / ライト」を任意に固定することも可能です。

### 14. 会話の長さ上限で新しいチャットへ自動切り替え
- ChatGPTで「この会話は長さの上限に到達していますが、新しいチャットを始めて会話を続けることができます。」と表示されたら、同じタブで新しいチャットを開きます。英語の上限警告にも対応しています。
- 残りのキューを順序・モデル・ツール指定ごと引き継いで自動送信を続けます。一時停止中の場合は停止状態を維持します。上限で拒否された送信もキューに保持します。
- 会話本文やコード内に同じ文言がある場合は切り替えません。過去の会話内容は新しいチャットには自動転記されません。

## インストール手順（Google Chrome）

1. Chromeを開き、アドレスバーに `chrome://extensions/` と入力して開きます。
2. 右上の **「デベロッパー モード」** のスイッチを **ON** にします。
3. 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 本プロジェクトのフォルダ（`chatgpt-queue`）を選択します。
5. [https://chatgpt.com/](https://chatgpt.com/) または [https://gemini.google.com/](https://gemini.google.com/) を開き、ページを更新すると画面右下にキューウィジェットが表示されます。

## 使い方

### 質問をキューに追加する
Geminiでは入力欄が空でも、入力欄付近に **Queue** ボタンと状態パネルを表示します。空欄のままQueueボタンを押すと、プロンプトの追加ダイアログを開けます。

1. **入力欄から**:
   - **Enter**: 入力中の質問をキューに追加して入力欄をクリア（直接送信せずキューにストック）。
   - **Shift + Enter**: 通常通り改行。
   - または、送信ボタンの横にある **`Queue` ボタン** をクリック。
2. **キューウィジェットの入力欄から**:
   - **Enter**: キューに追加。
   - **Shift + Enter**: 改行。
3. **一括追加**:
   - ウィジェット上部の「一括追加」ボタンから、複数行のプロンプトをまとめて登録。
4. **拡張機能のポップアップから**:
   - ブラウザのツールバーにある拡張機能アイコンをクリックして追加。

### キューの操作
- **一時停止**: ウィジェットの停止ボタンでいつでも自動送信を停止・再開できます。
- **今すぐ送信**: プロンプトカードの送信ボタンで最優先送信。
- **順序入れ替え**: 並び替えボタンで順序変更。
- **設定変更**: ウィジェットの設定ボタンから、思考待機時間やタイピング速度、テーマ、タイポ再現のON/OFFを設定可能。

### モデルを選択する（ChatGPT / Gemini）
1. 管理画面の入力欄にあるモデル選択ボタンを開きます。単一チャット表示・一覧表示の両方に対応しています。
2. 対象タブのモデルメニューを開いて、現在選択できるモデル名・IDを取得します。モデル名の固定リストやURLパラメータによる推測は使用しません。
3. モデルを選択すると、対象タブで切り替え、メニューの選択状態を確認した後に成功を表示します。
- **再取得**: プランやサービス側の候補が変わった場合は、モデル選択内の「再取得」を押してください。
- **現在の設定を使用**: キュー送信時にモデルを変更せず、サービス側の設定を使います。
- **指定モデルが選択できない場合**: プロンプトを保持したままキューを一時停止します。選択可能なモデルで送信待ち項目を登録し直してから再開してください。
- 取得できない場合は架空の候補を補いません。対象タブの別のメニューを閉じ、必要に応じて対象ページを再読み込みして再取得してください。

拡張機能のコードを更新した後は、Chromeの拡張機能一覧で再読み込みし、ChatGPT・Geminiと管理画面も再読み込みしてください。

### 参照元の表示
- 引用リンクはfaviconと引用元名を並べた高さ20pxのカードで表示します。長い名前は1行に省略し、ツールチップで全文とリンク先を確認できます。
- 複数の参照元は横並びで表示し、狭い列では横スクロールできます。
- 引用先のURLを取得できない場合はリンクを推測せず、リンク未取得の参照として表示します。faviconの取得に失敗した場合は小さな代替アイコンを表示します。
- Geminiの引用付き本文は通常の本文として保持します。表・箇条書き内の引用や回答のコピーでも、取得できた引用先を保持します。

## ファイル構成

```
chatgpt-queue/
├── manifest.json         # Chrome Extension Manifest V3 設定
├── background.js         # バックグラウンドサービスワーカー (ダッシュボード・タブ連携)
├── dashboard.html        # 全タブ一括管理ダッシュボード画面
├── dashboard.js          # ダッシュボードのリアルタイム同期＆遠隔操作ロジック
├── dashboard.css         # ダッシュボード専用デザイン (ダーク/ライト対応)
├── content.js            # タブ独立キュー・人間風シミュレーター・DOM監視
├── references.js         # 引用元の抽出・URL確認・コンパクトな参照カード
├── styles.css            # ウィジェットスタイル・アニメーション
├── typography.js         # タイポグラフィ標準設定
├── popup.html            # ツールバーポップアップ画面
├── popup.js              # ポップアップ制御ロジック
├── generate_icons.py     # アプリアイコン生成スクリプト
├── icons/                # アイコン画像群 (16x16, 48x48, 128x128, SVG)
└── README.md             # 本ドキュメント
```
